# 相册维护

相册入口是根目录的 `album.html`。在小家点击相册时，主页会打开这个独立页面；关闭后保留原来的小家场景。相册也可以单独打开。

相册只负责浏览照片、录像和滑动切换。截图与合照功能由小家主页负责。

## 当前浏览方式

媒体浏览窗口在屏幕内固定分为标题、展示区及日期与序号。照片与录像按原比例完整显示，切换内容时展示区不移动，不需要下滑。标题只显示一次。

已取消点画面全屏和“上一个／下一个”按钮。左右滑动切换照片与录像，关闭按钮左侧固定显示“滑动切换”。录像底部的播放、进度和声音控件继续使用浏览器原生控件，该区域不触发相册滑动。

录像先显示封面和“点击播放”，点击后才播放；切换到下一段时也先暂停。视频使用 `playsinline`、`webkit-playsinline` 和 `preload="none"`，没有自动播放调用。默认静音，声音由录像本身的控件调整；独立的“开启原声”按钮和重复提示已移除。

## 文件

- `content.js`：唯一的内容清单，按数组中的顺序显示，维护标题、日期和文件路径。
- `media/`：照片、录像和录像封面。当前 4 张照片、5 段录像及 5 张封面均从原版直接提取，未重新压缩。
- `album.js`：浏览交互。日常增删内容不需要修改。
- `../album.html`：相册界面及样式。

## 增加或修改内容

把新文件放进 `media/`，使用未占用的文件名，然后在 `content.js` 的数组中添加一项。例如：

```js
{
  "type": "photo",
  "title": "在院子里",
  "date": "2026年9月14日",
  "src": "album/media/photo-05.jpg"
}
```

录像使用 `"type": "video"`，`src` 指向录像，`poster` 指向封面照片；可用 `duration` 填写秒数。沿用现有录像的 MP4 格式最方便。

路径以根目录 `album.html` 为基准，统一写作 `album/media/文件名`。保留 `window.PANDA_ALBUM_ITEMS = [...]` 结构，各项之间用逗号分隔。调整数组顺序即可调整相册顺序。

主页打开时不加载相册。相册列表显示照片与录像封面，选中录像也先显示封面，点击播放后才开始播放。

## 移除内容

从 `content.js` 删除对应条目即可让它不再显示。确认文件没有被其他条目使用后，再删除对应的照片、录像或封面。清单可以留空，页面会显示空相册提示。

如果整个相册都不再需要，可移除主页的 `openAlbum` 入口、`albumOverlay` 容器、`.album-frame` 样式、入口脚本及相册关闭钩子，再删除 `album.html` 和 `album/`；同时更新主页使用说明中的相册介绍。相册没有被截图、合照或熊猫动作功能引用。

## 本地使用与发布

保持 `index.html`、`album.html` 和 `album/` 的相对位置。本地直接打开需要浏览器或查看器允许加载同目录文件；也可以通过本地网页服务预览。发布时把上述文件一起发布到同一站点。
